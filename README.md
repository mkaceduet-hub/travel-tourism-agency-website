# Wayfarer Travel Co. — Travel & Tourism Agency Website

A modern, responsive travel agency website concept built with HTML, CSS and vanilla JavaScript. The design highlights destinations, curated travel experiences and a simple enquiry flow.

## Features

- Editorial-style travel landing page with immersive hero section
- Destination cards with travel imagery
- Travel experience and agency introduction sections
- Trip enquiry form layout
- Responsive navigation for mobile and desktop
- Smooth in-page navigation and dynamic footer year
- Accessible labels, semantic sections and responsive styling

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts
- Unsplash image URLs

## Project Files

- `index.html` — page structure and content
- `style.css` — layout, visual design and responsive rules
- `script.js` — mobile menu and demo enquiry-form interaction

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Sublime Text or your preferred editor.
3. Open `index.html` in a browser.

No build tools or package installation are required.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

## Customization

- Replace the demo brand name, copy and destination details in `index.html`.
- Update the sample email address (`hello@wayfarer.example`) with your business email.
- Replace the Unsplash image URLs with your preferred licensed travel photography.
- Adjust colors and typography in the `:root` variables in `style.css`.

## Important Demo Note

The enquiry form is front-end only. It currently displays a demo confirmation message and does not send or store enquiries. Connect it to a backend or a form service before using this website for a real travel business. Contact details and brand content are placeholders.
